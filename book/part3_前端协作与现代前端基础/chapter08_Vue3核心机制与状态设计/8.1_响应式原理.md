# 响应式原理

> 学完本节，你能回答：Vue 3 为何用 Proxy 而非 `Object.defineProperty` 实现响应式？`ref` / `reactive` / `computed` / `watch` / `watchEffect` 各自解决什么问题？组合式 API 的生命周期钩子何时执行、如何与后端的请求生命周期对应？

## 从“数据变了视图不动”谈起

MeetingToText 的任务列表页有一个极简需求：输入框输入 `meeting`，列表只显示文件名包含 `meeting` 的任务。最朴素的实现是“手动重渲染”——每次 `keyword` 变化都手动调用 `render()`。一旦页面有 5 处依赖 `keyword`，就会出现“漏调一次就不同步”的经典 bug。

响应式的本质是把“手动调用”变为“自动订阅”——数据变化时，依赖它的视图与计算自动重算。类比后端的发布-订阅：数据是发布者，视图是订阅者。

## Proxy vs defineProperty：一字之差，能力之别

### defineProperty 的局限（Vue 2）

`Object.defineProperty` 劫持的是“已知的单个属性”：

```javascript
// 劫持单个属性：只对声明时存在的 key 生效
let val = ''
Object.defineProperty(obj, 'keyword', {
  get() { track(); return val },
  set(v) { val = v; trigger() }
})
// 新增属性无法被劫持 → 需 Vue.set(obj, 'newProp', 1)
// 数组需重写 push/pop 等变异方法才能追踪
```

局限有三：新增/删除属性需额外 API；数组索引与 `length` 需特殊处理；深层嵌套需递归劫持每个属性，初始化成本高。

### Proxy 的优势（Vue 3）

`Proxy` 代理的是“整个对象”，天然拦截所有操作：

```javascript
// 代理整个对象：新增/删除/数组索引均被拦截
const proxy = new Proxy(obj, {
  get(target, key) { track(target, key); return Reflect.get(target, key) },
  set(target, key, value) { const r = Reflect.set(target, key, value); trigger(target, key); return r },
  deleteProperty(target, key) { const r = Reflect.deleteProperty(target, key); trigger(target, key); return r }
})
// proxy.newProp = 1  自动触发，无需额外 API
// proxy.arr[0] = 'x' 亦被拦截
```

对后端开发者的翻译：`Proxy` 就像给对象套了一层“可观测代理网关”，所有读写都经网关自动“订阅/通知”——与后端的 AOP 拦截是同一思想在语言层面的实现。更多对比见 [7.3 为何选择 Vue 3 + Vite](../chapter07_前端开发概况与工程化演进/7.3_为何选择Vue3_Vite.md) 的概念对照。

## ref / reactive / computed / watch 的分工

| API | 解决的问题 | 后端类比 |
|-----|-----------|---------|
| `ref` | 单值响应式（`string`/`number`/`boolean`） | 盒子里的可观测值，`.value` 读写触发 |
| `reactive` | 对象/数组响应式（深层代理） | 可观测的 `dict`/`list` |
| `computed` | 派生状态，自动缓存、依赖变才重算 | 物化视图 / 缓存的派生字段 |
| `watch` | 显式监听某源，源变时执行副作用 | 显式订阅某 key |
| `watchEffect` | 自动收集依赖，依赖变即重跑 | 自动依赖追踪的订阅 |

```javascript
// 文件 book/samples/vue-min/src/App.vue 风格（组合式）
import { ref, reactive, computed, watch, watchEffect } from 'vue'

// ref：单值
const keyword = ref('')
keyword.value = 'meeting'  // 写 .value 触发

// reactive：对象
const state = reactive({ tasks: [], loading: true })

// computed：派生，带缓存
const filtered = computed(() => state.tasks.filter(t => (t.name || t.filename).includes(keyword.value)))

// watch：显式监听
watch(keyword, (newVal, oldVal) => { console.log(`keyword ${oldVal} → ${newVal}`) })

// watchEffect：自动收集
watchEffect(() => { console.log(`当前过滤结果 ${filtered.value.length} 条`) })
```

> **常见坑**：`ref` 在 JS 中需 `.value`，但模板中自动解包无需 `.value`；`reactive` 解构会丢失响应性，需 `toRefs` 或直接用 `ref`。

## 组合式 API 生命周期：与后端请求周期的对照

Vue 组件的生命周期对应一次“挂载—更新—卸载”的过程，可与后端的“请求处理周期”对照理解：

| Vue 钩子 | 时机 | 后端对照 |
|---------|------|---------|
| `setup` | 组件实例创建 | 构造函数 / 依赖注入 |
| `onMounted` | DOM 已挂载 | 服务就绪后首次拉数据（如 `load()`） |
| `onUpdated` | 响应式数据触发 DOM 更新后 | 状态变更后的副作用 |
| `onUnmounted` | 组件卸载 | 连接关闭、定时器清理 |

```javascript
// 典型生命周期用法（对应 vue-min 的 load 模式）
import { ref, onMounted, onUnmounted } from 'vue'

const tasks = ref([])
let timer = null

async function load() {
  const data = await fetch('/mock.json').then(r => r.json())
  tasks.value = data.tasks
}

onMounted(() => {
  load()
  timer = setInterval(load, 3000)  // 轮询任务状态
})
onUnmounted(() => clearInterval(timer))

// 对应后端的“启动时加载 + 定时轮询 + 关闭时清理”模式
```

`book/samples/vue-min/src/App.vue` 的 `onMounted(load)` 正是该模式的最小实现：挂载时拉取 `fetch('/mock.json')`，失败回退内置 mock，保证无后端也能渲染。

> **跨平台提示**：响应式与生命周期与操作系统无关；本地验证时用 `pathlib.Path` 处理路径，虚拟环境激活为 `source .venv/bin/activate`（macOS / Linux）与 `.venv\Scripts\activate`（Windows）。

## 可运行示例：Python 实现 Proxy 式响应式（ref / computed / watchEffect 简化版）

文件 `book/part3_前端协作与现代前端基础/chapter08_Vue3核心机制与状态设计/demo_reactive.py`（用 Python 类比 Vue 3 的 Proxy 响应式与生命周期，本地可复现，无网络）：

```{code-cell} ipython3
# 文件 book/part3_前端协作与现代前端基础/chapter08_Vue3核心机制与状态设计/demo_reactive.py
from typing import Callable

# ---- 1) Proxy 式响应式：拦截读写，自动追踪与触发 ----
class Dep:
    def __init__(self):
        self.subs: list[Callable] = []
    def depend(self, fn: Callable):
        if fn not in self.subs:
            self.subs.append(fn)
    def notify(self):
        for fn in list(self.subs):
            fn()

# 全局：当前正在收集依赖的 effect（类比 Vue 的 activeEffect）
_active_effect: list[Callable] = []

def watchEffect(fn: Callable):
    """自动收集依赖：执行 fn 时记录它访问了哪些响应式 key"""
    def wrapped():
        _active_effect.append(wrapped)
        try:
            fn()
        finally:
            _active_effect.pop()
    wrapped()
    return wrapped

class ReactiveDict:
    """Proxy 类比：代理整个 dict，新增/删除均可追踪"""
    def __init__(self, initial: dict):
        object.__setattr__(self, "_data", dict(initial))
        object.__setattr__(self, "_deps", {})  # key -> Dep

    def _dep(self, key) -> Dep:
        return self._deps.setdefault(key, Dep())

    def __getattr__(self, key):
        dep = self._deps.get(key)
        if dep and _active_effect:
            dep.depend(_active_effect[-1])
        # 若 key 不在 _data，返回 None（模拟 JS 的 undefined）
        return self._data.get(key)

    def __setattr__(self, key, value):
        if key in ("_data", "_deps"):
            object.__setattr__(self, key, value)
        else:
            existed = key in self._data
            self._data[key] = value
            # 新增属性也自动创建 Dep（对比 defineProperty 需额外 API）
            self._dep(key).notify()
            if not existed:
                print(f"  [Proxy] 新增属性 {key}={value!r} 自动可追踪（defineProperty 需额外 API）")

    def __delattr__(self, key):
        if key in self._data:
            del self._data[key]
            self._dep(key).notify()

# ---- 2) ref/computed/watch 的 Python 类比 ----
class Ref:
    """ref 类比：单值盒子，.value 读写触发"""
    def __init__(self, value):
        self._value = value
        self._dep = Dep()
    @property
    def value(self):
        if _active_effect:
            self._dep.depend(_active_effect[-1])
        return self._value
    @value.setter
    def value(self, nv):
        if nv != self._value:
            self._value = nv
            self._dep.notify()

class Computed:
    """computed 类比：派生 + 缓存，依赖变才重算"""
    def __init__(self, getter: Callable):
        self._getter = getter
        self._cached = None
        self._dirty = True
        self._dep = Dep()
        def on_dep_change():
            self._dirty = True
            self._dep.notify()
        self._on_dep_change = on_dep_change
        # 首次收集依赖
        def collect():
            _active_effect.append(on_dep_change)
            try:
                self._cached = self._getter()
            finally:
                _active_effect.pop()
            self._dirty = False
        watchEffect(collect)
        # 将 collect 的依赖转发为 computed 自身的 dirty 标记
        # 简化：直接用 watchEffect 重算缓存
        self._collect = collect
    @property
    def value(self):
        if _active_effect:
            self._dep.depend(_active_effect[-1])
        if self._dirty:
            _active_effect.append(self._on_dep_change)
            try:
                self._cached = self._getter()
            finally:
                _active_effect.pop()
            self._dirty = False
        return self._cached

def watch(source_fn: Callable, cb: Callable):
    """watch 类比：显式监听某源"""
    old = source_fn()
    def effect():
        nonlocal old
        new = source_fn()
        if new != old:
            cb(new, old)
            old = new
    watchEffect(effect)

# ---- 3) MeetingToText 场景：keyword + tasks → filtered ----
print("=== 响应式：Proxy vs defineProperty 心智 ===")
state = ReactiveDict({"keyword": "", "tasks": ["meeting.wav", "interview.mp3", "demo.wav"]})
keyword_ref = Ref("")

# computed 派生：keyword 变化自动重算
filtered = Computed(lambda: [t for t in state._data.get("tasks", []) if keyword_ref.value.lower() in t.lower()])

renders: list[str] = []
watchEffect(lambda: renders.append(" | ".join(filtered.value) if filtered.value else "(空)"))
print("初始:", renders[-1])
assert renders[-1] == "meeting.wav | interview.mp3 | demo.wav"

keyword_ref.value = "meeting"
print("keyword=meeting:", renders[-1])
assert renders[-1] == "meeting.wav"

# watch 显式监听
watch(lambda: keyword_ref.value, lambda n, o: print(f"  watch: {o!r} → {n!r}"))
keyword_ref.value = "mp3"
print("keyword=mp3:", renders[-1])
assert renders[-1] == "interview.mp3"

# Proxy 新增属性自动可追踪
state.new_field = "hello"
state.new_field = "world"
print("新增属性追踪通过（Proxy 无需额外 API）")

# computed 缓存：依赖不变时不重算
call_count = 0
def expensive_filter():
    global call_count
    call_count += 1
    return [t for t in state._data.get("tasks", []) if keyword_ref.value.lower() in t.lower()]
filtered2 = Computed(expensive_filter)
_ = filtered2.value
_ = filtered2.value  # 缓存命中
print(f"computed 缓存：两次读取仅计算 {call_count} 次（预期 1）")
assert call_count == 1
keyword_ref.value = "demo"
_ = filtered2.value  # 依赖变，重算
print(f"依赖变更后计算次数 {call_count}（预期 2）")
assert call_count == 2
print()

# ---- 4) 生命周期类比：onMounted/onUnmounted ----
print("=== 生命周期 ===")
lifecycle: list[str] = []
def onMounted(fn): lifecycle.append("mounted"); fn()
def onUnmounted(fn): lifecycle.append("unmounted"); fn()

tasks_loaded: list[str] = []
def load():
    tasks_loaded.extend(["meeting.wav", "interview.mp3"])
    print("  load: 任务已加载")

onMounted(load)
assert len(tasks_loaded) == 2
print("mounted 后任务数:", len(tasks_loaded))

# 模拟定时器清理
timer_active = True
def cleanup():
    global timer_active
    timer_active = False
    print("  cleanup: 定时器已清理")
onUnmounted(cleanup)
assert not timer_active
print("生命周期校验通过：挂载即加载，卸载即清理")
print()
print("小结：Proxy 代理对象而非属性，新增即响应；ref/reactive 管源，computed 管派生，watch 管副作用，生命周期管时机")
# 预期输出:
# === 响应式：Proxy vs defineProperty 心智 ===
# 初始: meeting.wav | interview.mp3 | demo.wav
# keyword=meeting: meeting.wav
#   watch: 'meeting' → 'mp3'
# keyword=mp3: interview.mp3
#   [Proxy] 新增属性 new_field=... 自动可追踪
# 新增属性追踪通过
# computed 缓存：两次读取仅计算 1 次
# 依赖变更后计算次数 2
# === 生命周期 ===
#   load: 任务已加载
# mounted 后任务数: 2
#   cleanup: 定时器已清理
# 生命周期校验通过
```
