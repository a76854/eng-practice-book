# 语音识别接入

> 把一段会议录音变成带时间戳与说话人的文本，链路是“签名鉴权 → 音频归一 → 模型推理 → 结果归一”。本节以后两步为核心，前一步用原理讲透，后一步用 `m2t` 真实跑通（无真实模型）。

## 为什么需要本节

MeetingToText 的上游是“任意用户上传的任意格式音频”，下游是“统一的段结构”。真实坑点常不在模型本身，而在：

- **鉴权签名**：云端 ASR 多用 HMAC-SHA256 对 `method + path + timestamp + body` 做签名，时间戳偏差 5 分钟即拒，后端必须做时钟容差与 nonce 去重。
- **格式不一致**：`m4a`/`mp3`/`ogg`/`wav`、8k/16k/44.1k、单声道/立体声，模型却只认“16k 单声道 float32”。
- **结果多形状**：同一模型在不同参数下返回 `sentence_info`、`timestamp` 或空结果，若每处各自解析，必遗漏分支。

> **中立性说明**：自建 FunASR 与云端 ASR 非互斥。自建可控、数据不出域，适合涉密场景；云端省运维、随用随付，适合峰值抖动大的业务。选型应基于数据合规、成本与峰值特征，而非技术潮流。

## 云端签名的最小心智

签名不是“加密”，是“防篡改的身份凭证”。典型流程：

1. 客户端用 `AK/SK` 对请求要素做 `HMAC`，得到 `Signature` 置于 `Authorization` 头。
2. 服务端用同一算法重算并比对，附带检验 `timestamp` 是否在允许窗口内。
3. 失败时返回 401/403，客户端不应重试签名错误的请求（重试也必败），应直接脱敏提示。

该流程与对象存储、网关鉴权同源，理解一次即可迁移。

## 音频归一：声道与采样率

`m2t/audio.py` 把归一拆为两步：

- `load_audio(path)`：用 `soundfile` 读任意格式，立体声按通道均值压为单声道，保持 `float32`。
- `resample_audio(samples, orig_sr, target_sr)`：若 `orig_sr == target_sr` 直接返回，否则用 `librosa` 重采样；未安装 `librosa` 时优雅降级为原样返回。

> **环境约定**：本书面向 Linux，`soundfile` 依赖系统 `libsndfile`，路径书写统一用 `pathlib.Path`，`/` 统一为 `/`。示例中临时文件均用 `tempfile` 创建，避免手写 `/tmp` 导致环境失败。

```bash
# 音频归一的环境校验
.venv/bin/python -c "from m2t.audio import load_audio; print(load_audio.__doc__[:20])"
```

## 结果归一：三种形状收敛为一种

`m2t/asr.py` 的 `normalize_result` 把 FunASR 的不稳定回包收敛为 `[{speaker, text, start, end}]`（时间由毫秒转秒）：

1. **`sentence_info` 带说话人**：每项含 `text`/`start`/`end`/`spk`（0 基转 1 基的“说话人N”）。
2. **`raw_text + timestamp` 回退**：用 `text` 与 `timestamp`（毫秒对）逐段对齐。
3. **空结果**：返回 `[]`，由调用方决定是否提示“未识别到语音”。

## 可运行示例：无真实模型的转写闭环

文件 `book/part4_advanced_engineering/chapter09_external_integration/demo_asr_audio.py`（音频归一与格式转换）：

```{code-cell} ipython3
import tempfile, pathlib
import numpy as np
import soundfile as sf
from m2t.audio import load_audio, resample_audio, load_and_resample

# 1) 合成一段立体声 48k 音频并落盘为 wav（无真实录音依赖）
sr_orig = 48000
duration = 0.5
t = np.linspace(0, duration, int(sr_orig * duration), endpoint=False)
tone = (0.3 * np.sin(2 * np.pi * 440 * t)).astype(np.float32)
stereo = np.stack([tone, tone * 0.8], axis=1)  # (N, 2)

with tempfile.TemporaryDirectory() as td:
    wav = pathlib.Path(td) / "synthetic.wav"
    sf.write(str(wav), stereo, sr_orig)

    # 2) load_audio：立体声 -> 单声道 float32
    samples, sr = load_audio(wav)
    print("loaded:", samples.shape, samples.dtype, "sr:", sr)
    assert samples.ndim == 1
    assert samples.dtype == np.float32
    assert sr == sr_orig

    # 3) resample_audio：48k -> 16k（若未装 librosa 则原样返回，行为仍确定）
    resampled = resample_audio(samples, sr, 16000)
    print("resampled:", resampled.shape, resampled.dtype)
    # 已装 librosa 时长度约为 1/3，未装时保持原长；两种皆合法，只校验类型
    assert resampled.dtype == np.float32

    # 4) 组合函数：一步到位得 16k 单声道
    s2, sr2 = load_and_resample(wav, target_sr=16000)
    print("load_and_resample sr:", sr2, "len:", len(s2))
    assert sr2 == 16000 or sr2 == sr_orig  # 未装 librosa 时为 orig
    print("音频归一校验通过")
# 预期输出:
# loaded: (24000,) float32 sr: 48000
# resampled: (24000,) float32 或 (8000,) float32（取决于是否安装 librosa）
# load_and_resample sr: 16000 或 48000
# 音频归一校验通过
```

文件 `book/part4_advanced_engineering/chapter09_external_integration/demo_asr_transcribe.py`（用 fake model 演示转写与归一，无真实模型/网络）：

```{code-cell} ipython3
from m2t.asr import transcribe, normalize_result

# 形状 1：sentence_info 带说话人（CAM++ 的 spk 为 0 基）
result_sentence = [{
    "sentence_info": [
        {"text": " 大家好，欢迎参加会议 ", "start": 0, "end": 1200, "spk": 0},
        {"text": "下面讨论与外部世界的集成", "start": 1200, "end": 2800, "spk": 1},
        {"text": "<|en|> hello <|zh|> ", "start": 2800, "end": 3500, "spk": 0},
    ]
}]
segs = normalize_result(result_sentence)
print("sentence_info:", segs)
assert segs[0]["speaker"] == "说话人1"
assert segs[1]["speaker"] == "说话人2"
assert segs[0]["start"] == 0.0
assert segs[1]["start"] == 1.2
assert segs[2]["text"] == "hello"  # _clean_text 去除 <|...|> 标签

# 形状 2：raw_text + timestamp 回退（无说话人）
result_raw = [{
    "text": "与外部世界的集成是必修课",
    "timestamp": [[0, 800], [800, 1500]]
}]
# 注意：单条 text 对应多段 timestamp 时，仅首段有文本（见 asr.py 注释）
segs2 = normalize_result(result_raw)
print("raw_text fallback:", segs2)
assert len(segs2) == 1
assert segs2[0]["end"] == 0.8

# 形状 3：空结果
assert normalize_result([]) == []
assert normalize_result([{}]) == []

# 无真实模型：注入 fake model，验证 transcribe 的归一链路
class FakeModel:
    def generate(self, input, cache, language, use_itn):
        return [{
            "sentence_info": [
                {"text": f"转写自 {input}", "start": 0, "end": 500, "spk": 0}
            ]
        }]

fake_segs = transcribe("meeting.wav", model=FakeModel(), language="auto")
print("transcribe with fake:", fake_segs)
assert fake_segs[0]["speaker"] == "说话人1"
assert "meeting.wav" in fake_segs[0]["text"]
assert fake_segs[0]["start"] == 0.0
print("转写归一校验通过：三种形状收敛为统一段结构")
# 预期输出:
# sentence_info: [{'speaker': '说话人1', 'text': '大家好，欢迎参加会议', 'start': 0.0, 'end': 1.2}, ...]
# raw_text fallback: [{'speaker': '', 'text': '与外部世界的集成是必修课', 'start': 0.0, 'end': 0.8}]
# transcribe with fake: [{'speaker': '说话人1', 'text': '转写自 meeting.wav', 'start': 0.0, 'end': 0.5}]
# 转写归一校验通过：三种形状收敛为统一段结构
```

> **工程启示**：把“音频归一”与“结果归一”收敛在 `m2t.audio` 与 `m2t.asr` 两个边界模块后，上层 pipeline 只需面对 `[{speaker, text, start, end}]`，无需关心底层是 FunASR 还是云端 ASR。该分层亦让单元测试可用纯内存数据 hermetic 验证。
