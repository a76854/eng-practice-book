# 前言

本书是一本面向“从算法与课程作业走向真实软件交付”的工程实践教材。它不围绕单一知识点展开，而是综合现实开发使用的工具链，结合已修习课程，再通过具体案例逐步加深。

本书面向已经掌握一门编程语言基础语法、能够完成课程作业与算法题，却尚未经历完整工程协作与系统交付的同学。如果你会写排序、懂一点语法，却在面对“如何把一个想法做成可运行、可测试、可部署、可维护的软件”时感到无从下手，那么这本书就是为你准备的。

## 目标读者与使用建议

本书的核心读者是计算机与软件工程专业的学生，尤其是修过程序设计、数据结构与算法，但缺乏规模化工程经验的同学。对于有一定项目经历的读者，本书可以帮助你把零散的工具与框架知识串成体系。对于从其他专业转向软件开发的读者，本书的循序渐进与案例也提供了友好的起点。

使用建议上，本书适合作为一学期的课程教材，也适合作为自学路线。正文共 12 章，建议按顺序阅读，因为后一章往往建立在前一章的工程约定之上。8 个实验与正文解耦，可以并行推进。每一章的正文都包含可运行示例，建议在本地 `.venv` 环境中亲手运行，观察输出，再尝试改动参数，理解背后的权衡。每章末尾设有小结与思考题，适合课堂讨论或小组复盘。

对于课堂使用，教师可将理论讲授与实验指导结合。实验承担练习与动手环节，采用 README 加 starter 的形式，提供任务说明与起始代码，不设标准解，以演示与讨论作为验收方式。学生应在阅读理论的同时完成对应实验，让概念在动手中有落脚点。

## “工程实践”思维

从 ACM/ICPC 竞赛代码到工业级软件，差别不在于算法是否巧妙，而在于代码是否能在时间、协作与变化中活下来。

竞赛代码追求在有限时间内解决确定性问题，输入输出明确，运行一次即结束，关注的是正确性与速度。工业级软件则不同，它要面对模糊的需求、持续的变更、多人并行的协作、复杂的运行环境与长期的维护成本。一段竞赛代码可以在单文件中用全局变量快速实现，而一个线上服务需要清晰的模块边界、可验证的类型、可复现的环境、可追踪的版本历史与可回滚的部署。

这种跃迁的核心是思维方式的转变。竞赛思维关注“如何解题”，工程思维关注“如何让解法在真实世界持续交付价值”。工程思维要求你在写下第一行代码前，先想清项目如何组织，依赖如何隔离，接口如何约定，测试如何保障，日志如何追踪，失败如何降级，协作如何不互相阻塞。本书的正文，正是沿着这条从个体解题到团队交付的路径展开。

这些挑战在任何需要长期维护的软件中都会出现。为让抽象概念有处落脚，本书以若干案例贯穿全篇，其算法本身并不复杂，不关注实现细节，不关注语法，业务逻辑与大模型都可调用现成服务。真正的工程挑战在于，如何把数据库、业务逻辑与前端协作串成一条可靠流水线，如何让不同同学在同一仓库中并行开发而不冲突，如何让一次依赖升级或一次线上异常不演变为全站故障。这些问题没有标准答案，只有在约束下权衡后的合理选择，这正是工程实践要训练的能力。但在第1章“开发者的元技能”中，我们会有意把案例后置，先用通用项目建立工程底座，再在每节末尾对照通用案例加深理解。

## 本书技术全景图

全书以 Python 生态为主线，同时覆盖后端架构与前端协作，让读者对现代 Web 应用的全链路有直观认识。

Python 生态是本书的起点与底座。第 1 章从项目结构、虚拟环境、Shell 与自动化脚本、Git 工作流讲起，帮助你建立可复现的工程底座。第 2 章在此之上构筑代码质量的护城河，类型标注、静态检查、测试与覆盖率共同保证代码在他人与时间面前依然可信。这两章不讲业务，却决定了后续所有业务代码能否稳健生长。

后端架构是本书的主体。第 3 至第 6 章展开全景，从后端职责与选型，到 HTTP 与 RESTful，再到数据持久化与并发模型，最后用一章综合实战把分层、HTTP 与持久化串成一条完整链路。FastAPI 与 Pydantic 作为主栈贯穿始终，搭配 SQLAlchemy 与 Alembic 完成从接口到存储的闭环。以文档搜索、收藏与摘要等通用场景为例，读者可以看到一个请求如何穿过路由、校验、服务、持久化与外部集成，每一层如何可测试与可替换。

前端协作是闭环的另一半。前端开发概况与 Vue3 核心这两章讲述前端在整体架构中的位置与现代前端的工程化基石，并以 Vue 3 与 Vite 为例，讲解响应式、组件化、路由与状态管理。重点不在语法细节，而在前后端如何通过契约协作。OpenAPI 契约、统一响应信封与类型共享，让前端不再猜测后端的返回，让联调从反复试错变为按契约验证。

与外部世界的集成、健壮性与安全底线、部署与持续集成这三章将视角拉向交付。外部集成的模式、对象存储与缓存、消息队列与大模型调用、认证与校验、错误边界与日志、容器化与持续集成，这些是把“能在本地跑通的项目”变为“能在服务器上持续运行的服务”所必需的工程能力。每一章都强调 trade-off，有数据说数据，无数据说代价，避免绝对化判断。

正文之后，8 个动手实验从工程初始化到全栈容器化答辩，与各章一一呼应。附录则提供课程设计大作业的通用选题，供学期项目选用。

全书结构一览：

- 开发者的元技能
- 构筑代码质量的护城河
- 后端开发概览
- HTTP 与 RESTful 架构
- 数据持久化
- 并发模型与性能工程
- 综合实战：一个注册接口贯穿三层
- 前端开发概况与工程化演进
- Vue3 核心机制与状态设计
- 与外部世界的集成
- 健壮性与安全底线
- 部署、容器化与持续集成
- 实验指导书
- 附录

本书所有示例均在 Python 3.12 与 Node 24 环境下验证，代码围栏区分可执行与展示，全书命令均面向 Linux。工程能力的提升没有捷径，只有在真实约束中反复练习，才能把“能写”变为“能交付”。希望本书能陪你走完这段从解题到造物的路。
