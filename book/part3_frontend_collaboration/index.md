# 前端协作与现代前端基础

本篇把视角从后端转向协作的另一端，前端。现代软件很少是纯后端系统， MeetingToText 这样的应用更是典型的全栈形态，文件上传、任务进度、结果展示与导出都发生在浏览器中。理解前端如何组织代码、如何与后端通过契约协作，是完成可交付产品的重要一环。

本篇不追求对前端框架的穷举，而是抓住协作与工程化的主线。先讲清前端在整体架构中的位置与演进逻辑，再聚焦到 Vue 3 的核心机制，让读者能够以后端工程师也能与前端顺畅对话的程度，参与联调与契约设计。重点在于边界与接口，而不是语法细节。

读完本篇，你将能够理解前端工程化的必要性，能够读懂并参与 Vue 3 项目的路由与状态设计，能够以后端视角参与接口契约的制定与验证，让前后端协作从反复试错变为按契约推进。

本篇包含以下两章：

- [第7章 前端开发概况与工程化演进](chapter07_frontend_overview/index.md)，从前端在架构中的角色出发，对比三大框架的定位与 trade-off，解释本书为何选择 Vue 3 加 Vite，并介绍前端工程化的构建、规范与协作基石
- [第8章 Vue 3 核心机制与状态设计](chapter08_vue3_core/index.md)，深入响应式原理、组件化设计、路由管理与 Pinia 状态管理，把前端从“拼页面”提升为“建系统”

建议在阅读本篇时同步完成实验六，让前端页面与状态管理在真实项目中得到练习，再为下一阶段的前后端联调做好准备。
