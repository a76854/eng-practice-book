# 路由管理

> 学完本节，你能回答：Vue Router 4 的两种历史模式有何差异、如何选择？路由守卫的执行顺序是什么、如何用它做鉴权与数据预取？路由懒加载如何与 Vite 的分包配合？

## 为何需要路由：从“多页刷新”到“单页切换”

MeetingToText 有三个页面：任务列表 `/tasks`、任务详情 `/tasks/:id`、上传页 `/upload`。若用传统多页，每次切换都整页刷新、状态丢失；单页应用（SPA）用前端路由在浏览器内切换视图，无刷新、状态可保持——路由就是“URL → 组件”的映射表。

类比后端：前端路由之于 SPA，如同 FastAPI 的 `APIRouter` 之于后端——都是“路径 → 处理器”的声明式映射，只不过前端的处理器是组件，后端的是函数。

## Vue Router 4 的核心三件套

### 1. 历史模式：hash vs html5

| 模式 | URL 形态 | 原理 | 适用 |
|------|---------|------|------|
| `createWebHashHistory` | `/#/tasks` | 监听 `hashchange` | 无需服务端配置，适合静态托管 |
| `createWebHistory` | `/tasks` | 依赖 `history.pushState` | URL 更干净，需服务端回退到 `index.html` |

MeetingToText 的 `dist/` 若由 Nginx 托管，`createWebHistory` 需配置 `try_files $uri /index.html`，否则直访 `/tasks/1` 会 404；hash 模式无此问题，但 URL 带 `#`。本课程示例默认用 hash 友好演示，生产可切 html5 + 回退。

```javascript
// 示意：router.ts
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),  // 或 createWebHashHistory()
  routes: [
    { path: '/', redirect: '/tasks' },
    { path: '/tasks', component: () => import('./views/TaskList.vue') },
    { path: '/tasks/:id', component: () => import('./views/TaskDetail.vue'), props: true },
    { path: '/upload', component: () => import('./views/Upload.vue') },
  ]
})
export default router
```

### 2. 路由守卫：导航的“安检链”

守卫是在“进入/离开某路由”时执行的钩子，典型用途是鉴权、埋点、数据预取。

执行顺序（类比后端的中间件洋葱模型）：

```
全局前置 beforeEach → 路由独享 beforeEnter → 组件内 beforeRouteEnter
→ 解析异步组件 → 组件内 beforeRouteUpdate（复用时）
→ 全局解析 beforeResolve → 导航确认 → 全局后置 afterEach
```

```javascript
// 全局守卫：鉴权（类比后端的 JWT 中间件）
router.beforeEach((to, from, next) => {
  const authed = !!localStorage.getItem('token')
  if (to.meta.requiresAuth && !authed) return next('/login')
  next()  // 放行；next(false) 取消；next('/other') 重定向
})

// 路由独享守卫：任务详情需先校验 id 合法
{
  path: '/tasks/:id',
  beforeEnter: (to) => {
    if (!/^\d+$/.test(to.params.id)) return '/tasks'
  }
}

// 组件内守卫：离开上传页前确认
import { onBeforeRouteLeave } from 'vue-router'
onBeforeRouteLeave((to, from) => {
  if (hasUnsavedChanges) return confirm('有未保存的修改，确定离开？')
})
```

对后端开发者的翻译：`beforeEach` 就是前端的“请求中间件”，`next()` 就是“放行/拦截/重定向”的决策点，与 FastAPI 的 `Depends(verify_token)` 是同一职责在不同层的实现。

### 3. 懒加载：按路由分包，按需加载

`component: () => import('./views/TaskList.vue')` 是动态导入，Vite/Rollup 会将其拆为独立 chunk，访问该路由时才加载——首屏更快、按需付费。

```javascript
// 懒加载 + 分组（webpackChunkName 注释在 Vite/Rollup 中亦可作 chunk 命名提示）
const TaskList = () => import('./views/TaskList.vue')
const TaskDetail = () => import(/* webpackChunkName: "task" */ './views/TaskDetail.vue')

// 预加载：空闲时提前拉取
// <link rel="prefetch"> 或 router 的 prefetch 选项（按需）
```

类比后端的“按需导入”——不访问的路由，其代码不进入首屏 bundle，如同不调用的接口不占运行时内存。

## 可运行示例：Python 演示路由匹配表 + 守卫链

文件 `book/part3_frontend_collaboration/chapter08_vue3_core/demo_router.py`（用 Python 模拟 Vue Router 的匹配、守卫链与懒加载分包，本地可复现，无网络）：

```{code-cell} ipython3
import re
from typing import Callable

# ---- 1) 路由表：path → component（含动态参数与懒加载标记） ----
class RouteRecord:
    def __init__(self, path: str, component: str, meta: dict | None = None, lazy: bool = False):
        self.path = path
        self.component = component
        self.meta = meta or {}
        self.lazy = lazy
        # 编译路径正则： /tasks/:id → ^/tasks/(?P<id>[^/]+)$
        pattern = re.sub(r":(\w+)", r"(?P<\1>[^/]+)", path)
        # 根路径特殊： / → ^/$
        if path == "/":
            pattern = r"/"
        self.regex = re.compile(f"^{pattern}$")

    def match(self, url: str) -> dict | None:
        m = self.regex.match(url)
        if not m:
            return None
        return m.groupdict()

routes = [
    RouteRecord("/tasks", "TaskList.vue", lazy=True),
    RouteRecord("/tasks/:id", "TaskDetail.vue", meta={"requiresAuth": True}, lazy=True),
    RouteRecord("/upload", "Upload.vue", lazy=True),
    RouteRecord("/login", "Login.vue"),
]

def match_route(url: str) -> tuple[RouteRecord | None, dict]:
    for r in routes:
        params = r.match(url)
        if params is not None:
            return r, params
    return None, {}

for url in ["/tasks", "/tasks/42", "/upload", "/unknown"]:
    rec, params = match_route(url)
    if rec:
        print(f"匹配 {url!r} → {rec.component} params={params} lazy={rec.lazy}")
    else:
        print(f"匹配 {url!r} → 404")
print()

# 校验：动态参数正确提取
rec, params = match_route("/tasks/42")
assert rec and rec.component == "TaskDetail.vue"
assert params == {"id": "42"}
print("路由匹配校验通过：/tasks/:id 正确提取 id=42")
print()

# ---- 2) 守卫链：全局前置 → 路由独享 → 解析 → 后置 ----
print("=== 守卫链（类比后端中间件洋葱） ===")

def global_before_each(to: dict, frm: dict) -> str | None:
    """全局前置：鉴权（类比 FastAPI 的 JWT 中间件）"""
    if to.get("meta", {}).get("requiresAuth") and not to.get("authed"):
        return "/login"  # 重定向
    return None

def route_before_enter(to: dict) -> str | None:
    """路由独享：校验 id 合法"""
    pid = to.get("params", {}).get("id")
    if pid is not None and not pid.isdigit():
        return "/tasks"
    return None

def before_resolve(to: dict) -> None:
    """解析守卫：数据预取（模拟）"""
    if to.get("path") == "/tasks/:id":
        print(f"  beforeResolve: 预取任务 {to['params']['id']} 的数据")

def after_each(to: dict, frm: dict):
    print(f"  afterEach: {frm.get('path','?')} → {to['path']} 完成（可埋点）")

def navigate(url: str, frm: dict | None = None, authed: bool = False):
    frm = frm or {"path": "?"}
    rec, params = match_route(url)
    if not rec:
        print(f"导航 {url!r} → 404")
        return None
    to = {"path": rec.path, "url": url, "params": params, "meta": rec.meta, "authed": authed}
    print(f"导航 {url!r} (authed={authed})")
    # 1) 全局前置
    redirect = global_before_each(to, frm)
    if redirect:
        print(f"  beforeEach 拦截 → 重定向 {redirect!r}")
        return redirect
    # 2) 路由独享
    redirect = route_before_enter(to)
    if redirect:
        print(f"  beforeEnter 拦截 → 重定向 {redirect!r}")
        return redirect
    # 3) 解析
    before_resolve(to)
    # 4) 确认 + 后置
    print(f"  导航确认 → 渲染 {rec.component} (lazy={rec.lazy})")
    after_each(to, frm)
    return rec.component

# 未登录访问需鉴权的详情页 → 被拦到 /login
assert navigate("/tasks/42", authed=False) == "/login"
# 已登录可进入
assert navigate("/tasks/42", authed=True) == "TaskDetail.vue"
# 非法 id → 被拦到 /tasks
assert navigate("/tasks/abc", authed=True) == "/tasks"
# 无需鉴权的列表页直接放行
assert navigate("/tasks", authed=False) == "TaskList.vue"
print("守卫链校验通过：鉴权/校验/预取/埋点按序执行")
print()

# ---- 3) 懒加载分包：按路由拆 chunk，首屏只加载当前路由 ----
print("=== 懒加载分包（按路由拆 chunk） ===")

chunks = {
    "TaskList.vue": "chunk-task-list.[hash].js",
    "TaskDetail.vue": "chunk-task-detail.[hash].js",
    "Upload.vue": "chunk-upload.[hash].js",
    "Login.vue": "chunk-login.[hash].js",
}

def load_chunk(component: str) -> str:
    c = chunks[component]
    print(f"  按需加载 {component} → {c}")
    return c

# 首屏访问 /tasks：只加载 TaskList 的 chunk
print("首屏 /tasks:")
load_chunk("TaskList.vue")
print("首屏未加载 TaskDetail/Upload 的 chunk（按需）")

# 切换到详情：再加载详情 chunk
print("切换 /tasks/42:")
load_chunk("TaskDetail.vue")
print("懒加载校验通过：首屏 1 chunk，切换时再按需 1 chunk")
print()

# ---- 4) 历史模式对照 ----
print("=== 历史模式 ===")
print("hash 模式:  /#/tasks  → hashchange，无需服务端回退，URL 带 #")
print("html5 模式: /tasks     → pushState，需 Nginx try_files $uri /index.html，否则直访 404")
print("本课程建议：开发期任意，生产用 html5 + 回退以获干净 URL")
print()
print("小结：路由表管映射，守卫链管放行，懒加载管分包；三者共同实现 SPA 的页面间导航")
# 预期输出:
# 匹配 '/tasks' → TaskList.vue params={} lazy=True
# 匹配 '/tasks/42' → TaskDetail.vue params={'id': '42'} lazy=True
# 路由匹配校验通过
# === 守卫链 ===
# 导航 '/tasks/42' (authed=False)  ... 重定向 '/login'
# 导航 '/tasks/42' (authed=True)  ... 渲染 TaskDetail.vue
# 守卫链校验通过
# === 懒加载分包 ===
# 首屏 /tasks: 按需加载 TaskList.vue → chunk-task-list.[hash].js
# ...
# 懒加载校验通过
# === 历史模式 ===
# hash 模式:  /#/tasks ...
# html5 模式: /tasks ...
```
