# 实验指导书

本部分是全书的动手部分，与正文 13 章理论配套。理论负责把原理讲透，实验负责把能力练熟。理论章不设练习与评分，动手与验收统一由本部分承担。

与以往按章配套不同，本部分**按领域编排**：前两个实验打磨工程底座，其后四个实验沿一条“文档查询”主线逐层长大，先做后端，再做前端，然后接入外部能力，最后完成容器化交付。实验之间是递进关系，后一个实验建立在前一个的成果之上，建议按顺序完成，也可根据课程进度灵活组合。

共 6 个实验：

- [实验一 课程作业整理工具](homework_organizer.md)，按学号与 Excel 名单重命名作业并按班级归档，贯通 `uv`、`argparse`、`pathlib`、`Makefile` 与 Git 分支
- [实验二 成绩等级评定系统](grade_analysis.md)，用类型校验、静态检查与单元测试为项目加上质量护城河，并接入持续集成门禁
- [实验三 文档查询后端](backend.md)，用 FastAPI 与三层架构实现搜索与收藏，完成持久化与迁移，并加上最小可用的登录与令牌校验
- [实验四 文档查询前端](frontend.md)，用 Vue3、Vue Router 与 Pinia 完成搜索与收藏面板，实现登录拦截与跨组件状态
- [实验五 大模型摘要与缓存](external_services.md)，在实验三的后端上接入大模型摘要与 Redis 旁路缓存，处理流式返回与降级
- [实验六 容器化部署与持续交付](deployment.md)，用 Nginx 托管前端、容器化后端，编排 Compose 并写好持续集成与回滚

## 验收方式

- 每个实验以“可演示、可解释、可复现”为标准：能现场运行，能当众解释设计取舍，助教按 `README.md` 能在约定时间内复现。
- 不设自动判分脚本，评分以实验报告与现场答辩为准。
- 提交物为你的代码仓库、`README.md` 与实验报告，具体要求见各实验文档。

## 环境约定

- 所有实验均在书仓根目录的 `.venv` 环境中复现，包管理与依赖声明以 `uv` 为准。
- 环境约定为 Linux，路径统一写 `/`；前端依赖由各实验自己的 `package.json` 管理。
- 需要密钥的实验（大模型调用）统一从环境变量读取，未配置时走降级分支，不影响其余功能。
