# 数据持久化

> **本章学习目标**
> - 能够用实体、属性、关系三要素画出 ER 图，并把它翻译成带主键、外键与约束的表结构
> - 能够用标准库 `sqlite3` 的 DDL 建库，并说明索引的用途与代价
> - 能够用参数化查询与事务安全地访问数据库，说明防注入与一致性的原理
> - 能够用 SELECT、WHERE、聚合、JOIN 与子查询完成单表与跨表查询
> - 能够对比 SQL 与 ORM 的优缺点，按场景做出选型

> **为什么需要掌握本章**
> 程序处理的数据只活在内存里，进程一退出就消失。后端把"可计算"变成"可记忆"，靠的就是持久化。本章沿着数据流转的路径走一遍：先建模想清楚有哪些数据、什么关系，再建库把模型落成表，然后用参数化与事务安全地读写，用 SQL 把散在表里的数据查询出来，最后用 ORM 把重复劳动省掉。全程用标准库 `sqlite3` 可验证，让数据既存得下，也查得出。

> **预计理论学时**：3学时
