# SQL 进阶

> 学完本节，你能回答：`JOIN` 的六种写法在语义上有何差异？子查询与 `JOIN` 何时可互换？窗口函数为什么能“一行看全组”而不 collapsing 行？

## 从单表到多表：JOIN 是关系的“连线”

单表查询回答“这张表里有什么”，多表查询回答“这些表之间有什么关系”。类比学生与选课：`students` 存人，`enrollments` 存选课记录，二者通过 `student_id` 连线。

| JOIN 类型 | 语义 | 记忆 |
|-----------|------|------|
| `INNER JOIN` | 只要两边都匹配才保留 | 交集 |
| `LEFT JOIN` | 左表全保留，右表缺失补 `NULL` | 左全集 |
| `RIGHT JOIN` | 右表全保留（SQLite 用 `LEFT` 对调实现） | 右全集 |
| `FULL OUTER JOIN` | 两边全保留（SQLite 用 `UNION` 模拟） | 并集 |
| `CROSS JOIN` | 笛卡尔积 | 排列组合 |
| `SELF JOIN` | 自己与自己连 | 层级/配对 |

> **选型中立性**：`JOIN` 与子查询在多数场景可互换，优化器常能改写为同一执行计划。以“可读性优先、必要时看 `EXPLAIN QUERY PLAN`”为准，不做绝对化偏好。

## 子查询：把查询当作值来用

- **标量子查询**：返回单行单列，可直接参与 `WHERE` 比较。
- **`IN` / `EXISTS` 子查询**：判断集合成员或存在性，`EXISTS` 在大表下常更高效（找到即停）。
- **派生表**：`FROM (SELECT ...)` 把子查询当临时表再查一次，适合分步聚合。

## 窗口函数：不折叠行的“分组透视”

`GROUP BY` 会把多行压成一行；窗口函数在**保留每一行**的同时，让每一行都能看到分组内的聚合与排序。

```sql
ROW_NUMBER() OVER (PARTITION BY status ORDER BY created_at)  -- 组内行号
RANK()       OVER (ORDER BY duration DESC)                    -- 排名（并列跳号）
SUM(duration) OVER (PARTITION BY status)                      -- 组内求和但不折叠
```

类比班级排名：`GROUP BY` 告诉你“每班平均分”，窗口函数告诉你“每个同学在班内的名次”——后者保留了每个同学的行。

> **兼容性**：SQLite 3.25+ 支持窗口函数（`ROW_NUMBER` / `RANK` / `SUM() OVER` 等）。Python 3.12 自带 `sqlite3` 通常满足该版本；若本地版本过低，升级 Python 或 SQLite 即可。

## 可运行示例：JOIN、子查询、窗口函数

文件 `book/part2_backend_development/chapter05_persistence_sql_orm/demo_sql_advanced.py`（单文件演示三类查询，无网络）：

```{code-cell} ipython3
# 文件 book/part2_backend_development/chapter05_persistence_sql_orm/demo_sql_advanced.py
import sqlite3

conn = sqlite3.connect(":memory:")
conn.row_factory = sqlite3.Row
# 建两张表：tasks（任务）与 segments（转写片段，演示一对多）
conn.executescript("""
CREATE TABLE tasks (
    id TEXT PRIMARY KEY,
    filename TEXT NOT NULL,
    status TEXT NOT NULL,
    duration INTEGER NOT NULL,
    created_at TEXT NOT NULL
);
CREATE TABLE segments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id TEXT NOT NULL REFERENCES tasks(id),
    speaker TEXT NOT NULL,
    text TEXT NOT NULL
);
""")
# 写入示例数据（刻意让不同 status 的 duration 有区分，便于窗口函数观察）
tasks = [
    ("t1", "a.wav", "completed", 120, "2026-01-01 10:00:00"),
    ("t2", "b.wav", "completed", 90,  "2026-01-02 11:00:00"),
    ("t3", "c.wav", "pending",   60,  "2026-01-03 12:00:00"),
    ("t4", "d.wav", "pending",   30,  "2026-01-04 13:00:00"),
]
conn.executemany("INSERT INTO tasks VALUES (?, ?, ?, ?, ?)", tasks)
segments = [
    ("t1", "Alice", "hello"),
    ("t1", "Bob", "world"),
    ("t2", "Alice", "foo"),
    ("t3", "Bob", "bar"),
]
conn.executemany("INSERT INTO segments (task_id, speaker, text) VALUES (?, ?, ?)", segments)
conn.commit()

# 1) JOIN：INNER vs LEFT —— t4 无 segment，INNER 会丢、LEFT 会保留
inner = conn.execute("""
SELECT t.id, s.speaker FROM tasks t INNER JOIN segments s ON s.task_id = t.id ORDER BY t.id, s.id
""").fetchall()
print("INNER JOIN rows:", len(inner), [(r["id"], r["speaker"]) for r in inner])
assert len(inner) == 4

left = conn.execute("""
SELECT t.id, s.speaker FROM tasks t LEFT JOIN segments s ON s.task_id = t.id ORDER BY t.id, s.id
""").fetchall()
print("LEFT JOIN rows:", len(left), [(r["id"], r["speaker"]) for r in left])
# t4 的 speaker 为 NULL
assert len(left) == 5
assert left[-1]["id"] == "t4" and left[-1]["speaker"] is None

# 2) 子查询：EXISTS 找出“至少有一条 segment”的任务
exists_rows = conn.execute("""
SELECT id FROM tasks t WHERE EXISTS (SELECT 1 FROM segments s WHERE s.task_id = t.id) ORDER BY id
""").fetchall()
print("EXISTS:", [r["id"] for r in exists_rows])
assert [r["id"] for r in exists_rows] == ["t1", "t2", "t3"]

# 标量子查询：duration 大于平均 duration 的任务
avg_rows = conn.execute("""
SELECT id, duration FROM tasks WHERE duration > (SELECT AVG(duration) FROM tasks) ORDER BY id
""").fetchall()
print("above avg:", [(r["id"], r["duration"]) for r in avg_rows])
assert [r["id"] for r in avg_rows] == ["t1", "t2"]  # avg=75

# 派生表：先按 status 聚合，再筛选组大小 >1 的状态
derived = conn.execute("""
SELECT status, cnt FROM (SELECT status, COUNT(*) AS cnt FROM tasks GROUP BY status) WHERE cnt > 1 ORDER BY status
""").fetchall()
print("derived:", [(r["status"], r["cnt"]) for r in derived])
assert len(derived) == 2

# 3) 窗口函数：组内行号、排名、组内求和（保留每一行）
print("sqlite version:", sqlite3.sqlite_version)
win = conn.execute("""
SELECT
    id,
    status,
    duration,
    ROW_NUMBER() OVER (PARTITION BY status ORDER BY duration DESC) AS rn,
    RANK()       OVER (ORDER BY duration DESC) AS rk,
    SUM(duration) OVER (PARTITION BY status) AS sum_by_status
FROM tasks ORDER BY status, duration DESC
""").fetchall()
for r in win:
    print(dict(r))
# 校验：completed 组内最长的 t1 rn=1，pending 组内最长的 t3 rn=1
assert win[0]["id"] == "t1" and win[0]["rn"] == 1
assert win[2]["id"] == "t3" and win[2]["rn"] == 1
# 组内求和：completed 210, pending 90
assert win[0]["sum_by_status"] == 210
assert win[2]["sum_by_status"] == 90

conn.close()
print("SQL 进阶校验通过：JOIN/子查询/窗口函数均按预期")
# 预期输出:
# INNER JOIN rows: 4 [...]
# LEFT JOIN rows: 5 [...]
# EXISTS: ['t1', 't2', 't3']
# above avg: [('t1', 120), ('t2', 90)]
# derived: [('completed', 2), ('pending', 2)]
# sqlite version: 3.4x.x
# {'id': 't1', 'status': 'completed', 'duration': 120, 'rn': 1, 'rk': 1, ...}
# SQL 进阶校验通过：JOIN/子查询/窗口函数均按预期
```
