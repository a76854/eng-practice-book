# 用 SQLite 与 SQLAlchemy 建库

> 学完本节，你能回答：如何用 DDL 把 5.1 的 ER 图落成可运行的库表？`students / courses / enrollments` 三张表的主键、外键、索引应如何声明？`sqlite3` 与 `SQLAlchemy` 在“建库”这一步有何异同？

## 承接 5.1：从 ER 到 DDL

5.1 用 ER 图建立了实体、属性与关系的契约，本节把契约落到 DDL。以学生管理系统为例，ER 已给出三类实体：

- `students` —— 学生档案，`id` 为主键，`email` 唯一；
- `courses` —— 课程目录，`id` 为主键；
- `enrollments` —— 选课记录，多对多关联表，`student_id` 指向 `students(id)`，`course_id` 指向 `courses(id)`，二者组合加学期唯一约束。

本节只讲建库 DDL，查询与关联过滤留给 5.3。

## ① 标准库 `sqlite3` 建库：DDL 可运行

`sqlite3` 是 Python 标准库，无需额外安装即可在 `.venv` 中执行。下例用单文件完成建库、索引与外键约束的声明与校验：

```{code-cell} ipython3
import sqlite3

conn = sqlite3.connect(":memory:")
conn.execute("PRAGMA foreign_keys = ON")
print("sqlite_version:", sqlite3.sqlite_version)
print("foreign_keys:", conn.execute("PRAGMA foreign_keys").fetchone()[0])

# DDL 建库：三张表 + 主键/外键/索引
conn.executescript("""
CREATE TABLE students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE
);

CREATE TABLE courses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    credit INTEGER NOT NULL DEFAULT 3
);

CREATE TABLE enrollments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    student_id INTEGER NOT NULL,
    course_id INTEGER NOT NULL,
    semester TEXT NOT NULL,
    score INTEGER,
    UNIQUE(student_id, course_id, semester),
    FOREIGN KEY (student_id) REFERENCES students(id) ON DELETE CASCADE,
    FOREIGN KEY (course_id) REFERENCES courses(id) ON DELETE CASCADE
);

CREATE INDEX idx_enrollments_student ON enrollments(student_id);
CREATE INDEX idx_enrollments_course ON enrollments(course_id);
CREATE INDEX idx_students_email ON students(email);
""")
conn.commit()

# 校验：表与索引均已创建
tables = [r[0] for r in conn.execute("SELECT name FROM sqlite_master WHERE type='table' ORDER BY name").fetchall()]
print("tables:", tables)
assert "students" in tables and "courses" in tables and "enrollments" in tables

indexes = [r[0] for r in conn.execute("SELECT name FROM sqlite_master WHERE type='index' ORDER BY name").fetchall()]
print("indexes:", indexes)
assert "idx_enrollments_student" in indexes
assert "idx_enrollments_course" in indexes

# 写入示例数据并验证主键/外键/唯一约束
conn.execute("INSERT INTO students (name, email) VALUES (?, ?)", ("张三", "zhangsan@example.com"))
conn.execute("INSERT INTO students (name, email) VALUES (?, ?)", ("李四", "lisi@example.com"))
conn.execute("INSERT INTO courses (title, credit) VALUES (?, ?)", ("数据库原理", 3))
conn.execute("INSERT INTO courses (title, credit) VALUES (?, ?)", ("操作系统", 4))
conn.commit()

# 合法选课
conn.execute("INSERT INTO enrollments (student_id, course_id, semester, score) VALUES (?, ?, ?, ?)", (1, 1, "2026-spring", 92))
conn.commit()
print("enrollments count:", conn.execute("SELECT COUNT(*) FROM enrollments").fetchone()[0])
assert conn.execute("SELECT COUNT(*) FROM enrollments").fetchone()[0] == 1

# 外键校验：不存在的学生应失败（需 foreign_keys=ON）
try:
    conn.execute("INSERT INTO enrollments (student_id, course_id, semester) VALUES (?, ?, ?)", (999, 1, "2026-spring"))
    conn.commit()
    raise AssertionError("foreign key should have failed")
except sqlite3.IntegrityError as e:
    print("foreign key check:", e)
    conn.rollback()

# 唯一约束：同一学生同一课程同一学期不得重复
try:
    conn.execute("INSERT INTO enrollments (student_id, course_id, semester) VALUES (?, ?, ?)", (1, 1, "2026-spring"))
    conn.commit()
    raise AssertionError("unique should have failed")
except sqlite3.IntegrityError as e:
    print("unique check:", e)
    conn.rollback()

# 级联与索引：验证 PRAGMA table_info 与 index_list
print("students columns:", [r[1] for r in conn.execute("PRAGMA table_info(students)").fetchall()])
print("enrollments fk:", conn.execute("PRAGMA foreign_key_list(enrollments)").fetchall())
print("enrollments indexes:", [r[1] for r in conn.execute("PRAGMA index_list(enrollments)").fetchall()])

conn.close()
print("建库校验通过：students/courses/enrollments 主键/外键/索引均按预期")
# 预期输出:
# sqlite_version: 3.4x.x
# foreign_keys: 1
# tables: ['courses', 'enrollments', 'sqlite_sequence', 'students']
# indexes: [...]
# enrollments count: 1
# foreign key check: FOREIGN KEY constraint failed
# unique check: UNIQUE constraint failed: enrollments.student_id, enrollments.course_id, enrollments.semester
# 建库校验通过：...
```

要点小结：

- `PRIMARY KEY` 与 `UNIQUE` 保证实体唯一性与业务唯一性；
- `FOREIGN KEY ... REFERENCES ... ON DELETE CASCADE` 在数据库层约束关联完整性，需 `PRAGMA foreign_keys = ON` 方可生效；
- `CREATE INDEX` 为高频过滤列 `enrollments(student_id)` 与 `enrollments(course_id)` 建索引，写入时同步维护、以读加速换写成本。

```bash
# 查看表结构
.venv/bin/python -c "import sqlite3; c=sqlite3.connect(':memory:'); c.executescript('CREATE TABLE students(id INTEGER PRIMARY KEY, name TEXT);'); print(list(c.execute(\"SELECT sql FROM sqlite_master WHERE type='table'\")))"
```

## ② `SQLAlchemy` 声明式建库：示意（不执行）

同等 DDL 可用 `SQLAlchemy 2.0` 的声明式模型表达，表结构由 Python 类生成，建库由 `Base.metadata.create_all` 一次完成。以下为示意围栏，不在本书 `.venv` 中执行，仅展示形态：

```python
# pip install sqlalchemy
from sqlalchemy import String, Integer, ForeignKey, UniqueConstraint, Index, create_engine
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, relationship

class Base(DeclarativeBase):
    pass

class Student(Base):
    __tablename__ = "students"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String, nullable=False)
    email: Mapped[str] = mapped_column(String, nullable=False, unique=True)

    enrollments: Mapped[list["Enrollment"]] = relationship(back_populates="student", cascade="all, delete-orphan")

    __table_args__ = (
        Index("idx_students_email", "email"),
    )

class Course(Base):
    __tablename__ = "courses"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    title: Mapped[str] = mapped_column(String, nullable=False)
    credit: Mapped[int] = mapped_column(Integer, nullable=False, default=3)

    enrollments: Mapped[list["Enrollment"]] = relationship(back_populates="course", cascade="all, delete-orphan")

class Enrollment(Base):
    __tablename__ = "enrollments"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    student_id: Mapped[int] = mapped_column(ForeignKey("students.id", ondelete="CASCADE"), nullable=False)
    course_id: Mapped[int] = mapped_column(ForeignKey("courses.id", ondelete="CASCADE"), nullable=False)
    semester: Mapped[str] = mapped_column(String, nullable=False)
    score: Mapped[int | None] = mapped_column(Integer, nullable=True)

    student: Mapped["Student"] = relationship(back_populates="enrollments")
    course: Mapped["Course"] = relationship(back_populates="enrollments")

    __table_args__ = (
        UniqueConstraint("student_id", "course_id", "semester", name="uq_enrollment_semester"),
        Index("idx_enrollments_student", "student_id"),
        Index("idx_enrollments_course", "course_id"),
    )

# 建库：由模型生成 DDL，无需手写 CREATE TABLE
# engine = create_engine("sqlite+pysqlite:///:memory:")
# Base.metadata.create_all(engine)
```

> **选型提示**：`sqlite3` 的 DDL 手写直观、依赖为零，适合教学与小工具；`SQLAlchemy` 的声明式模型把表结构收敛为 Python 类，配合 `Alembic` 可做版本化迁移，适合表多、关联多的生产项目。二者在“建库”语义上等价，差异在于“谁持有表定义的权威来源”——SQL 文本 vs Python 模型。
