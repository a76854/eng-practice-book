# 为何选择 FastAPI

> 学完本节，你能回答：本书为何在 Django / Flask / FastAPI 中选择 FastAPI + Pydantic？异步原生、自动文档、类型安全三点如何对应 MeetingToText 的真实约束？

## 选型回到约束

课程主栈不是“追新”，而是约束求解。MeetingToText 的三条硬约束直接对应 FastAPI 的三项能力：

1. **I/O 密集与可扩展**：音频上传、ASR 与 LLM 调用均为 I/O 等待，服务需在等待期间让出线程、支撑并发。FastAPI 基于 Starlette 与 `asyncio` 原生支持异步，同步与异步可在同一应用中共存。
2. **契约先行与前后端协作**：前端与后端的唯一契约是 OpenAPI。FastAPI 从类型标注与 Pydantic 模型自动生成 OpenAPI 与交互式文档（Swagger UI / ReDoc），契约即代码、代码即文档。
3. **类型安全与可维护**：团队协作与长期维护依赖“形状可检查”。FastAPI + Pydantic 把请求/响应的形状从文档约束变为运行时校验 + 静态类型提示，非法输入在边界即被拦截，而非深入业务后才暴露。

> **中立性说明**：这三点是“在本课程约束下”的优势，而非绝对优越。若场景是后台管理密集、定制少、团队熟悉 Django 约定，则 Django 的全栈可能是更低成本的选择；若是极小原型且无需类型与文档，Flask 的轻量可能是更快路径。选型结论始终附带前提。

## 异步原生：让等待不再阻塞

```python
# 同步：等待 ASR 时线程被占用
def transcribe_sync(file): 
    return asr_model(file)  # 阻塞

# 异步：等待时让出事件循环，同一进程可服务更多请求
async def transcribe_async(file):
    return await asr_service(file)  # 非阻塞，等待期间处理其他请求
```

FastAPI 允许同步与异步路由共存，I/O 密集路径用 `async`、CPU 密集或存量同步代码用 `def`，无需全量重写。真实性能瓶颈往往在数据库与外部服务，框架的异步是“放大器”而非“银弹”，需结合端到端压测验证。

## 自动文档：契约即代码

定义一个 Pydantic 模型与路由，`/docs` 即得交互式文档，无需手写 YAML。前端可据此生成请求代码，后端改动即文档改动，契约漂移在 CI 中即可发现（将在 [第4章的 OpenAPI 契约测试](../../part2_backend_development/chapter04_http_restful/4.5_openapi_contract_test.md) 中展开）。

## 类型安全：FastAPI + Pydantic 的组合

Pydantic 在边界做**解析与校验**（parse, don't validate）：输入先被解析为模型，失败则返回 422，成功则下游拿到的是已校验、已带类型的对象。配合 `mypy` 与编辑器提示，形状错误在提交前即被捕获。

> **环境约定**：本书面向 Linux，`uvicorn` 的启动与文档访问在各平台一致；`http://127.0.0.1:8000/docs` 在 Linux 上均为同一地址，差异仅在浏览器打开方式与终端激活命令。

## 可运行示例：Pydantic 模型 + 路由（自动校验与文档）

文件 `book/part2_backend_development/chapter03_backend_essence/demo_fastapi_pydantic.py`（单文件演示类型安全与自动文档，无网络）：

```{code-cell} ipython3
# 文件 book/part2_backend_development/chapter03_backend_essence/demo_fastapi_pydantic.py
from enum import Enum
from typing import Annotated

from fastapi import FastAPI, Query
from fastapi.testclient import TestClient
from pydantic import BaseModel, Field, field_validator

# --- Pydantic 模型：形状即校验 ---
class TaskStatus(str, Enum):
    pending = "pending"
    processing = "processing"
    done = "done"

class TaskCreate(BaseModel):
    task_id: str = Field(min_length=1, max_length=64, description="任务 ID")
    filename: str = Field(min_length=1, description="文件名")
    language: str = Field(default="zh", pattern=r"^[a-z]{2}(-[A-Z]{2})?$", description="语言标签")

    @field_validator("task_id")
    @classmethod
    def no_spaces(cls, v: str) -> str:
        if " " in v:
            raise ValueError("task_id must not contain spaces")
        return v

class TaskOut(BaseModel):
    id: str
    filename: str
    status: TaskStatus
    language: str

# 内存存储（教学简化，真实项目由 m2t.store.TaskStore 持久化）
db: dict[str, TaskOut] = {}

app = FastAPI(title="FastAPI+Pydantic Demo")

@app.post("/tasks", response_model=TaskOut, tags=["tasks"])
def create_task(payload: TaskCreate):
    task = TaskOut(id=payload.task_id, filename=payload.filename, status=TaskStatus.pending, language=payload.language)
    db[task.id] = task
    return task

@app.get("/tasks/{task_id}", response_model=TaskOut, tags=["tasks"])
def get_task(task_id: str):
    # 路径参数的校验由 FastAPI 自动处理
    if task_id not in db:
        from fastapi import HTTPException
        raise HTTPException(status_code=404, detail="not found")
    return db[task_id]

@app.get("/search", tags=["tasks"])
def search(q: Annotated[str, Query(min_length=1, max_length=50, description="关键词")] = "demo"):
    # 查询参数的校验与文档同样自动生成
    return {"q": q, "hits": [k for k in db if q in k]}

client = TestClient(app)

# 1) 正常创建
r1 = client.post("/tasks", json={"task_id": "t1", "filename": "meeting.wav", "language": "zh"})
print("create t1:", r1.status_code, r1.json())
assert r1.status_code == 200
assert r1.json()["status"] == "pending"

# 2) 校验失败：task_id 含空格 → 422（Pydantic 边界拦截）
r2 = client.post("/tasks", json={"task_id": "bad id", "filename": "a.wav"})
print("bad id:", r2.status_code, r2.json()["detail"][0]["type"])
assert r2.status_code == 422

# 3) 校验失败：language 格式错误 → 422
r3 = client.post("/tasks", json={"task_id": "t2", "filename": "a.wav", "language": "not-a-lang"})
print("bad lang:", r3.status_code)
assert r3.status_code == 422

# 4) 查询参数校验
r4 = client.get("/search", params={"q": "t1"})
print("search t1:", r4.json())
assert "t1" in r4.json()["hits"]

# 5) 自动文档：OpenAPI schema 中包含模型与路径
schema = app.openapi()
print("openapi has TaskCreate:", "TaskCreate" in str(schema))
print("paths:", sorted(schema["paths"].keys()))
assert "/tasks" in schema["paths"]
assert "/tasks/{task_id}" in schema["paths"]
# 校验：TaskCreate 的 task_id 有 minLength 约束（来自 Field）
task_create_schema = schema["components"]["schemas"]["TaskCreate"]
print("TaskCreate properties:", sorted(task_create_schema["properties"].keys()))
assert "task_id" in task_create_schema["properties"]

print("FastAPI+Pydantic 校验通过：类型即文档，边界即防线")
# 预期输出:
# create t1: 200 {'id': 't1', ...}
# bad id: 422 ...
# bad lang: 422
# search t1: {'q': 't1', 'hits': ['t1']}
# openapi has TaskCreate: True
# paths: ['/search', '/tasks', '/tasks/{task_id}']
# TaskCreate properties: ['filename', 'language', 'task_id']
# FastAPI+Pydantic 校验通过：类型即文档，边界即防线
```

```bash
# 启动并查看自动文档
.venv/bin/uvicorn demo_fastapi_pydantic:app --reload --port 8000
# 浏览器打开 http://127.0.0.1:8000/docs
```
